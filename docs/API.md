# API Reference

Base URL: `{API_URL}/api/v1` · Interactive docs (non-production): `{API_URL}/docs`

Auth: `Authorization: Bearer <accessToken>` unless marked **public** or **internal** (`x-internal-key` header).
Errors: `{ statusCode, message, errors?: [{path, message}], path, timestamp }`.

## Auth
| Method | Path | Body | Notes |
|---|---|---|---|
| POST | `/auth/register` | `{email, password, name?}` | public · 5/min → `{accessToken, user}` |
| POST | `/auth/login` | `{email, password}` | public · 10/min |
| POST | `/auth/oauth` | `{email, name, image, provider, providerAccountId}` | internal (called by Auth.js) |
| GET | `/auth/me` | | current user |

| GET | `/resumes/:id/download` | → `{url}` presigned (5 min) |

| POST | `/resumes/:id/reparse` | |
